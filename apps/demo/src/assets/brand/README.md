# OriginLM brand artwork

Copied from the supplied OriginLM asset pack ("Matched Cuts"). The shell draws
the small-size optical mark inside an amber tile as the app icon; the horizontal
lockups are kept for exports and documentation.

| File | Use |
| --- | --- |
| `originlm-mark-small-graphite.svg` | Symbol on the amber app tile (light and dark) |
| `originlm-mark-small-white.svg` | Reversed symbol on dark artwork |
| `originlm-horizontal-white.svg` | White lockup for dark surfaces |
| `originlm-horizontal-graphite.svg` | Graphite lockup for light surfaces |

Brand values: graphite `#231F20`, amber `#EBA31A`, off-white `#FAF9F5`.

Logo rights are unverified; see `crates/lai-desktop/assets/brand/PROVENANCE.md`
for the asset pack's own rights record. The bundled font licence covers the font
software only.

The browser tab icon is the pack's `web/favicon.svg` and `favicon-32.png`, copied
to `public/` and linked from `index.html`.
